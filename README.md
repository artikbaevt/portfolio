# Porfolio

Был сделан анализ данных телеком-компаний

🛠️ **Используемый стек и инструменты**

Excel: Очистка данных, Power Query,Power Pivot, формулы, построение сводных таблиц и сводных дашбордов.

📈 Ключевые метрики проекта (KPIs)

| Метрика            | Значение | Аналитический контекст                    |

| База клиентов      | 6 000    | Очищено от дубликатов                     |

| Churn Rate (Отток) | 25.5%    | 1 530 отключенных клиентов из 6 000       |

**Главные находки и бизнес-инсайты**

 1. ADSL — самый проблемный сегмент
* Срок жизни клиентов у всех типов подключения одинаков (~11.5–12 месяцев), но ADSL теряет в 2 раза больше клиентов;

2. Обращения в поддержку как предиктор оттока
Наблюдается прямая зависимость между тикетами и уходом клиента:
* 0 обращений → Churn 22.5%
* чем больше обращений → Churn тоже растёт.

---

💡 **Рекомендации для бизнеса**
1. Мигрировать клиентов с ADSL на GPON..
2. Запустить (скидки/приоритетный сервис) при достижении клиентом 4+ обращений в поддержку.
3. Учитывать незавершённость данных за последний месяц (май/июнь 2026), чтобы избежать ложных паник из-за визуального «спада» выручки.
